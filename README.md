# LEAD HUNTER AI

Реализованы девять независимых сценариев, очередь источников/CRM, подписанная форма,
версии публикаций через Postiz и локальный FFmpeg/Pillow с реестром прав.
Текущий тест запускается в этой облачной сессии; это не постоянный VPS.
Актуальные ограничения и доступы: [STATUS](docs/STATUS.md),
[каналы](docs/CHANNELS.md), [контент/медиа](docs/PUBLISHING_AND_MEDIA.md),
[развёртывание](docs/HOSTING.md).

Telegram-пульт для квалификации потенциальных клиентов русскоязычного веб-разработчика.
Реализован **этап A**: разрешённый JSON/CSV или DEMO → n8n → нормализация → эвристика/
необязательная OpenAI-оценка → PostgreSQL → карточки и очередь Telegram владельца.

Начните с [START_HERE.md](START_HERE.md). Полный стек — два контейнера; Python
transport нужен только для подключения Telegram. Отдельного backend и собственной CRM нет.

```bash
python3 scripts/setup.py
docker compose up -d --wait
python3 scripts/migrate.py
python3 scripts/connect.py
python3 scripts/import-workflows.py --activate-local
python3 scripts/demo.py
```

По умолчанию внешние ключи не требуются, расходы OpenAI и публикации отключены.
DEMO-компании вымышлены; `.invalid` ссылки не являются результатами поиска.
Пустое поле сайта означает `UNKNOWN`, а не доказанное отсутствие сайта.

## Состав

| Компонент | Назначение |
|---|---|
| n8n 2.43.6 | Расписания, команды, HTTP-интеграция, импортируемые workflow |
| PostgreSQL 17.11-alpine | Лиды, миграции, дедупликация, DNC, одобрения, бюджет, outbox |
| Python 3.12+ standard library | Локальная настройка, импорт, polling/delivery Telegram, backup/restore |
| Node.js 24+ built-ins | Нормализация, карточки, schema validation и генератор workflow |

Основные workflow: `01-lead-import.json`, `02-telegram.json`, `03-notifications.json`,
`04-openai-score.json`. Стандартные ноды; community nodes не используются.
Исходный шаблон 15411 недоступен через политику сети: workflow реализован самостоятельно,
а не выдан за проверенную адаптацию. См. [источники и решения](docs/SOURCES_AND_DECISIONS.md).

## Telegram

После безопасного внесения токена и admin ID в `.env`:

```bash
python3 scripts/connect.py
python3 scripts/import-workflows.py --activate-local
python3 scripts/telegram_transport.py --check
python3 scripts/telegram_transport.py
```

Команды: `/start`, `/today`, `/find maps_demo`, `/find maps_demo мебель|Самара`,
`/leads`, `/leads high`, `/leads medium`, `/lead ID`, `/draft ID новый текст`,
`/approve ID версия`, `/reject ID`, `/sources`, `/stats`, `/budget`, `/stop`, `/resume`.
`/threads`, `/instagram` и `/videos` показывают честный статус дальнейших модулей.

Одобрение действует на конкретную версию черновика для **ручной** отправки. Каналов
автоматической отправки КП в этапе A нет. Одобрение не переводит лид в CONTACTED.
Команда `/approve ID` без версии ничего не одобряет: используйте кнопку свежей
карточки или `/approve ID версия`.
Изменение черновика снимает одобрение; `/reject` устанавливает DNC.
При STOP сбор и AI выключаются, уведомления о лидах ждут; управляющие ответы владельцу
доставляются, чтобы он мог увидеть статус и возобновить работу.

Polling/delivery adapter занимается только транспортом; данные и правила находятся в
n8n/PostgreSQL. После неоднозначного сетевого результата сообщение получает UNCERTAIN
и не отправляется повторно вслепую. Повторять getUpdates с другим процессом нельзя.

HTTPS webhook, эксплуатация и восстановление: [OPERATIONS.md](docs/OPERATIONS.md).

## OpenAI и бюджет

Responses API опционален. `AI_ENABLED=false` и нулевые цены отключают расходы, даже если
ключ добавлен. Для включения заполните `OPENAI_API_KEY` (в облаке также поддерживается
`LH_OPENAI_API_KEY`), `OPENAI_MODEL`, обе актуальные цены за миллион токенов и
`AI_ENABLED=true`; повторите connect/import. Ключи вводятся только в защищённые
настройки или локальный `.env`. Модель не получает инструментов и права отправлять сообщения.

Сначала применяются эвристики, LLM получает только score≥40. Проверяются структура,
диапазоны, точная цитата из источника; отказ, timeout, 429 и некорректный JSON дают
помеченную эвристическую оценку. Кэш разделён по контенту, модели, версии схемы/промпта
и mock-режиму. Тестовые ответы называются `openai_mock`.
После свежего ответа и после кэша повторно применяется ограничение свежести:
старый/недатированный прямой запрос не получает приоритет ≥90. Неопределённая
идентичность компании требует REVIEW и ограничивается 69 баллами. Мобильные
поддомены соцсетей не объединяются в одну компанию; DEMO отделён от реальных данных.

Дневной UTC-лимит резервируется атомарно в PostgreSQL. По умолчанию $1, 50 вызовов,
100 лидов за запуск. Вход оценивается консервативно по байтам + запас, выход ≤600
токенов; ошибки не возвращают резерв. Реальный биллинг зависит от текущих цен
провайдера: это приблизительная защита, а не гарантированный банковский лимит.

`AUTOPUBLISH=false`, `AUTO_OUTREACH=false`, `VIDEO_GENERATION_PAID=false`,
`MAX_PUBLIC_POSTS_PER_DAY=2` сохраняются для следующих этапов. Публикаторы и платные
видеогенераторы в текущем коде отсутствуют; установка этих флагов в true их не создаёт.

## Разработка и проверки

```bash
npm test
node scripts/build-workflows.js
python3 scripts/import-workflows.py --activate-local
python3 scripts/verify.py
```

Установка npm-зависимостей не нужна. Генератор встраивает проверенные JS-модули в
Code nodes, поэтому после изменения `lib/` следует пересобрать JSON и импортировать их.
Полная проверка использует настоящие n8n/PostgreSQL и локальные HTTP-моки, включая
timeout, лимит бюджета, повторный импорт и backup/restore. Её запускают до привязки
настоящего владельца/платного API; для подключённой системы используйте отдельную
DEMO-копию с собственными Compose volumes и портом.

Команды импортера перезаписывают **наши четыре workflow по стабильным ID** и
активируют локальные webhooks/расписания только с `--activate-local`. Сохраните свои
изменения в редакторе экспортом или backup до повторного импорта. Чужие workflow
импортер не перечисляет для удаления и не удаляет.

## Статус и стоимость

Таблица всех девяти способов, Threads, Instagram и видео: [STATUS.md](docs/STATUS.md).
Фактические проверки текущей сборки: [VERIFICATION.md](docs/VERIFICATION.md).

DEMO не использует платные источники и LLM: расход API $0. Для сервера заложите
примерно $5–15/месяц за небольшой VPS; это ориентир, не тариф поставщика.
При бюджете $1/сутки максимальный запланированный резерв — около $30 за 30 суток;
фактические расходы могут быть ниже и требуют проверки биллинга.
Postiz, NocoDB, браузерный краулер и видеогенераторы не установлены и не оплачиваются.

На этой amd64-машине после запуска наблюдалось около 370 MiB RAM для n8n и 40 MiB
для PostgreSQL без тяжёлых задач; практический стартовый запас — 2 GiB RAM и 10+ GiB
диска, для активного LLM/больших импортов запас больше. Образы публикуются для amd64
и arm64, но исполнение на ARM в этой среде не проверено. Oracle Always Free зависит
от фактических квот и наличия VM; 2 OCPU/12 GB не гарантируются.
