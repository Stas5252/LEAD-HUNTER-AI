# Подсистема C: карусели и Video Factory

Статус: одобрено пользователем 2026-10-15; выполнение в текущей сессии. Контекст: [общая спецификация](2026-10-15-completion-design.md).

## Цель

Дёшево создавать собственные русскоязычные материалы: шаблонные карусели и короткие
вертикальные ролики из разрешённых исходников, с предпросмотром владельцу и
подтверждённой очередью публикации. Дорогая генерация выключена.

## Данные и права

references — ссылки на форматы/идеи, не разрешение скачивать чужое видео.
assets хранят content hash, проверенный локальный путь, media type/duration,
source URL, правообладателя, лицензию/основание, дату и явное подтверждение прав.
Использование чужих материалов без указанного основания блокируется.
Разрешены собственные материалы, лицензированные клипы и проверенные стоки.
API стоков подключаются только после проверки текущих правил и ключей.

Для полностью автономных тестов создаются собственные синтетические DEMO-клипы
и шаблонные карточки; они не выдаются за найденные тренды или коммерческую работу.

## Монтаж

FFmpeg/ffprobe — зрелый исполнитель, небольшие адаптеры формируют команды без shell.
Сценарий описывает порядок сцен, осмысленные надписи, длительности, субтитры, CTA
и выбранную разрешённую аудиодорожку. Разные версии отличаются сценарием/порядком/
содержанием; нет изменений ради обхода fingerprint.

Задачи ограничены по времени, длительности, размеру, числу сцен и CPU; по умолчанию
один render одновременно. Входы/выходы находятся только под media root, запрещены
traversal/symlinks наружу и произвольные FFmpeg protocols/filters из пользовательского
текста. Заголовки/пути не интерполируются в shell. Контроль наличия кодеков/шрифтов
выполняется перед стартом; артефакты проверяются ffprobe и контрольным декодированием.

Экономный TTS необязателен: подключается проверенный локальный движок/голос с
разрешённой лицензией либо предоставленная владельцем озвучка. Отсутствующий TTS
не выдаётся за сгенерированный звук. Music source/license фиксируются отдельно.
MoneyPrinterTurbo и платные генераторы не устанавливаются без подтверждённой пользы,
совместимости, разрешения и бюджета.

## Карусели и preview

Шаблоны 5–7 карточек используют проверенный рендерер текста/изображений, реальные
услуги и корректные русские шрифты. Не генерировать платную картинку на каждую карточку.
Черновик/preview показываются владельцу через Telegram; файл привязан к asset/job ID.
Права на локальные пути не передаются через произвольный chat payload.

Состояния idea → script → asset_ready → rendering → preview → approved → queued.
Изменение сценария или артефакта меняет hash/версию и отзывает approval.
В публикации передаётся только проверенный артефакт с подтверждёнными правами.
Сам факт рендера не является разрешением опубликовать.

## Приёмка и эксплуатация

Собственный DEMO-клип проходит rights check → два содержательно различных сценария
→ FFmpeg → ffprobe/decode → preview payload → approval → publication queue.
Проверяются отсутствие прав, path/shell injection, повреждённый файл, timeout,
повторный job, STOP, отозванное approval и ограничения ресурсов.

Медиа-worker можно выполнять на сервере или ПК владельца. Сохранённые артефакты и
очереди переживают перезапуск; незавершённые задания восстанавливаются без двойной
публикации. Настоящая доставка Telegram и Postiz/Meta проверяется с подключёнными
аккаунтами отдельно от локального render test.
